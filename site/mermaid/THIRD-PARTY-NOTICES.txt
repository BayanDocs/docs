Third-party notices for site/mermaid/mermaid.min.js

mermaid.min.js is the unmodified dist/mermaid.min.js file from the npm package mermaid 11.17.2 (https://mermaid.js.org, https://www.npmjs.com/package/mermaid). Mermaid bundles code from other packages into that one file. Each package and its copyright notice are listed below; the full license texts are in the LICENSES folder at the root of this repository (MIT.txt, ISC.txt, BSD-3-Clause.txt, MPL-2.0.txt and Apache-2.0.txt). The license comments that Mermaid's build keeps at the end of mermaid.min.js (DOMPurify, Lodash and code embedded in Cytoscape) are left in place.

The list covers Mermaid's runtime dependency tree, resolved from npm on 2026-10-04; the exact versions inside the bundle may differ slightly, and some listed packages may have been left out of the bundle by its build. Two kinds of package from the tree are not listed: type-declaration packages (@types/* and @chevrotain/types), which contain no code, and robust-predicates (Unlicense), whose code is not in the bundle (checked by searching the bundle for its constants; see site/mermaid/README.md).
